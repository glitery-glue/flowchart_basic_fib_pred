🏥 Basic Fibrosis Prediction

LLM-Based Few-Shot Learning Pipeline

📁
STEP 1: Patient Data

Load training and test datasets from CSV files containing patient clinical data.

Input Data

  • Training Set: Historical patient records with known fibrosis stages
  • Test Set: Patients to classify (currently filtering F2+ cases)
  • Features: 33 clinical parameters per patient
  • Labels: F0, F1, F2, F3, F4 (fibrosis stages)

📊
STEP 2: Normalize & Format Target Patient

Convert patient data into structured format with proper units and labels.

Processing Steps

  • Extract patient features (demographics, vitals, labs)
  • Create a Feature Schema. Format as JSON with value, unit, and label for each feature
  • Prepare for LLM consumption (human-readable format)

Example Output

  • "Age": { "value": 43.0, "unit": "years", "label": "Age" }, "Gender": { "value": 1.0, "unit": "", "label": "Sex" },

STEP 3: Find K-Nearest Neighbors (KNN)

Find K=5 most similar patients from training set using normalized Euclidean distance.

⚠️ CRITICAL PRINCIPLE: Cluster by INPUT, NOT Output

  • Remove label column (fib_stage_gt) before computing similarity
  • Compute Euclidean distance on normalized features
  • Select K=5 nearest neighbors
  • Return original rows WITH labels (for few-shot learning)

Feature Weighting (Future Enhancement)

Current: Unweighted | Recommended: Clinical importance weights

High Priority (3.0x): ALT, AST, Platelets, FIB-4
Medium Priority (2.0x): Age, BMI, Glucose, HbA1c

STEP 4: Format Few-Shot Examples

Convert the K=5 similar patients into structured format WITH their labels.

Few-Shot Learning Structure

  • Patient 1: [All features] → Fibrosis Stage: F2
  • Patient 2: [All features] → Fibrosis Stage: F3
  • Patient 3: [All features] → Fibrosis Stage: F2
  • Patient 4: [All features] → Fibrosis Stage: F2
  • Patient 5: [All features] → Fibrosis Stage: F3

Purpose: LLM learns patterns from similar cases to predict the target patient's stage.

Load AASLD-aligned clinical knowledge and reasoning rules.

Clinical Context Includes

STEP 6: Load RALPH Loop Instructions

Add self-audit and iterative refinement instructions.

RALPH = Refinement And Loop-based Prediction Heuristic

  • Pass 1: Initial prediction with step-by-step reasoning
  • Pass 2: Self-audit (check calculations, guidelines, confounders)
  • Pass 3: Refine prediction based on audit findings

Goal: Reduce errors and hallucinations through iterative self-correction.
